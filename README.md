# XM4 Control

Веб-панель управления наушниками **Sony WH-1000XM4** прямо из браузера, без установки программ.
Работает через Web Serial: подключается к служебному Bluetooth-каналу наушников (тому же, что использует приложение Sony Headphones Connect).

**Открыть:** https://evonext.github.io/xm4/

> Неофициальный проект, не связан с Sony. Протокол восстановлен по открытым разборам и проверен вручную на WH-1000XM4.

## Возможности

| Раздел | Что умеет |
|---|---|
| Батарея | Заряд и признак зарядки, процент во вкладке, предупреждение при низком заряде (пуш или плашка на странице) |
| Воспроизведение | Название, исполнитель и альбом текущего трека, обложка и длительность (поиск в Deezer / iTunes), плей/пауза, переключение треков, громкость 0–30 |
| Визуалайзер | Имитация по состоянию воспроизведения, громкости и эквалайзеру; на компьютере — режим «Живой звук» с настоящим спектром системного звука |
| Шумоподавление | Шумодав / окружающий звук / выкл, уровень окружающего звука 1–20, фокус на голосе |
| Функции | Speak-to-Chat, DSEE Extreme, пауза при снятии, автоотключение |
| Эквалайзер | Пресеты, ручная настройка 5 полос и Clear Bass (−10…+10) |
| Интерфейс | Полноэкранный «пульт» на больших экранах, горячие клавиши, русский и английский язык (выбирается автоматически по языку браузера), установка на главный экран Android |

## Требования

- **Компьютер:** Chrome или Edge 117+ (Windows, macOS, Linux).
- **Android:** Chrome 137+ и разрешение Chrome «Устройства поблизости».
- Наушники должны быть **спарены и подключены** к устройству через системные настройки Bluetooth.
- Firefox и Safari не поддерживают Web Serial.

## Как пользоваться

1. Открой https://evonext.github.io/xm4/
2. Нажми **«Подключить»** и выбери WH-1000XM4. Страница подключается только к служебному каналу управления **Serial HPC**, поэтому в списке будут только сами наушники.

Дальше браузер запомнит разрешение, и страница будет подключаться сама при открытии.

### Горячие клавиши (компьютер)

| Клавиша | Действие |
|---|---|
| `Space` | плей / пауза |
| `←` `→` | предыдущий / следующий трек |
| `↑` `↓` | громкость |
| `1` `2` `3` | шумодав / окружающий звук / выкл |
| `F` | во весь экран |
| `L` | журнал протокола |

### Android

- Установи как приложение: меню Chrome → «Добавить на главный экран».
- Если открыто приложение Sony Headphones Connect, оно может занимать канал управления — закрой его через «Недавние».
- Кнопки «Живой звук» на телефоне нет: мобильный Chrome не умеет захватывать системный звук.

## Если не подключается

| Симптом | Что сделать |
|---|---|
| «Совместимые устройства не найдены» (компьютер) | Наушники должны быть подключены в настройках Bluetooth. Удали и заново спарь наушники при открытом браузере |
| «Совместимые устройства не найдены» (Android) | Дай Chrome разрешение «Устройства поблизости», проверь версию Chrome (`chrome://version`, нужна 137+) |
| Порт открыт, но наушники не отвечают | Закрой Sony Headphones Connect на телефоне, отключись и подключись снова |
| Пуш о заряде «запрещён» | Открывай страницу по ссылке `https://…`, а не как локальный файл: для `file://` браузер не запоминает разрешения |
| Нет обложки или длительности | Трека нет в каталогах Deezer / iTunes или сеть их блокирует. Подробности — в журнале (`L`), строки «поиск …» |

## Конфиденциальность

Всё работает в браузере, своего сервера у проекта нет. Наружу уходят только поисковые запросы «исполнитель + название» в Deezer и iTunes — чтобы найти обложку и длительность. Настройки (порог уведомления) хранятся в браузере.

## Протокол (для разработчиков)

Транспорт — Bluetooth RFCOMM, служба **Serial HPC** `96cc203e-5068-46ad-b32d-e316f5e069ba`. Страница подключается только к ней.

**Кадр:** `3E | тип | seq | длина (4 байта, BE) | данные | контрольная сумма | 3C`
- тип `0C` — данные, `01` — подтверждение (ACK, seq = 1 − seq полученного);
- контрольная сумма — сумма байтов от типа до конца данных по модулю 256;
- байты `3C 3D 3E` внутри кадра экранируются: `3D` + (байт & `EF`).

**Команды** (запрос → ответ; уведомления приходят без запроса):

| Функция | Запрос | Ответ / уведомление | Установка | Проверено |
|---|---|---|---|---|
| Инициализация | `00 00` | `01 …` | — | ✅ |
| Модель / прошивка | `04 01` / `04 02` | `05 01 len str` / `05 02 len str` | — | ✅ |
| Батарея | `10 00` | `11 00 уровень зарядка`, `13 …` | — | ✅ |
| Шумоподавление | `66 02` | `67 02 …` / `69 02 …` | `68 02 вкл(11/00) 02 nc(02/00) 01 голос уровень` | ✅ |
| Эквалайзер | `56 01` | `57 01 пресет 06 полосы…` | `58 01 пресет 00`; ручной: `58 01 A0 06 b0…b5` (значение + 10) | ✅ |
| DSEE Extreme | `E6 02` | `E7 02 00 вкл` | `E8 02 00 вкл` | ✅ |
| Громкость | `A6 01 20` | `A7/A9 01 20 уровень` (0–30) | `A8 01 20 уровень` | ✅ |
| Состояние плеера | `A2 01 00` | `A3/A5 01 00 состояние` (01 играет, 02 пауза) | — | ✅ |
| Управление плеером | — | — | `A4 01 00 код`: 01 пауза, 02 след., 03 пред., 07 плей | ✅ |
| Теги трека | `A6 01 поле` | `A7 01 поле 02 len utf8` (00 название, 01 альбом, 02 исполнитель, 03 жанр) | — | ✅ |
| Speak-to-Chat | `F6 05` | `F7 05 00 вкл`, `F9 05 01 вкл` | `F8 05 01 вкл 01` | ✅ включение, выключение не подтверждено |
| Пауза при снятии | `F6 03` | `F7 03 00 вкл` | `F8 03 00 вкл` | ✅ |
| Автоотключение | `F6 04` | `F7 04 01 a b` | `F8 04 01 a b`: `11 00` не отключать, `10 00` когда сняты | ✅ чтение |
| Настройки Speak-to-Chat | `FA 05` | — | `FC 05 чувств. время` | ❌ догадка |

Не найдено: включение/выключение сенсорной панели (команда `D8 D2 …` принимается, но не действует), позиция и длительность трека (наушники их не знают).

## Устройство проекта

| Файл | Назначение |
|---|---|
| `index.html` | Всё приложение: разметка, стили, протокол и интерфейс в одном файле, без зависимостей |
| `sw.js` | Service worker — нужен для уведомлений на Android и установки на главный экран |
| `manifest.webmanifest`, `icon-*.png` | Манифест и иконки для установки как приложения |

Сборки нет: правишь `index.html` → коммит → GitHub Pages публикует за 1–2 минуты. Локально страницу можно открыть и как файл, но тогда браузер не запоминает разрешения.

## English

Browser-based control panel for **Sony WH-1000XM4**. No install needed: it talks to the headphones' control channel over Bluetooth via the Web Serial API.

**Open:** https://evonext.github.io/xm4/ — the UI language follows your browser language (Russian or English).

**Features:** battery level and low-battery alert; now-playing title, artist and album with cover art and duration (looked up on Deezer / iTunes); play/pause, track skip, volume; visualizer (simulated, or real system-audio spectrum on desktop); noise cancelling / ambient sound with level 1–20 and focus on voice; Speak-to-Chat, DSEE Extreme, pause when taken off, auto power off; equalizer presets and manual bands; full-screen dashboard with keyboard shortcuts; installable on Android.

**Requirements:** Chrome or Edge 117+ on desktop, or Chrome 137+ on Android (grant Chrome the *Nearby devices* permission). The headphones must be paired and connected in the system Bluetooth settings.

**Usage:** open the page → **Connect** → pick WH-1000XM4. The page only connects to the *Serial HPC* control service. The browser remembers the permission and reconnects automatically next time.

**Privacy:** everything runs in your browser; the only outgoing requests are artist + title searches on Deezer and iTunes for cover art and duration.

**Protocol:** see the table above — frame format, service UUIDs and the commands verified on WH-1000XM4.

Unofficial project, not affiliated with Sony.
